# My Portfolio 
A personal digital business card and project showcase. While initially inspired by a web development course, it has been completely reimagined with a custom design to reflect my personal brand and technical journey.

💡 Overview & Evolution
This project serves as a central hub for my professional identity. To ensure the result was truly unique, I conducted a complete visual overhaul, implementing a custom dark/light mode and a sophisticated purple-accented aesthetic based on community feedback.

🌟 Key Features

* **Custom UI/UX:** A fully responsive, handcrafted design featuring smooth CSS animations and transitions.

* **Dynamic Rendering:** Utilizes Flask and Jinja2 macros to manage project cards and sections efficiently, ensuring code reusability.

* **Dual Theme Support:** Integrated dark and light modes to provide a personalized viewing experience.

* **Continuous Integration:** A live roadmap tracking my progress as I add new subpages for major projects like the Ekonomik Inventory and SecurEnv.

🛠 Tech Stack

* **Backend:** Python / Flask (Routing & Templating)

* **Frontend:** HTML5, CSS3 (Custom animations, Keyframes)

* **Logic:** Jinja2 Macros for modularity
